3. HP Feedback: User Experience (evaluate whether to change) to evaluate

HP's feedback on points with a poorer experience; all are pending evaluation.

  • to evaluate [BSP] Palm affects the stylus: the palm often interferes with the stylus, worsening the writing experience; keeping the hand hovering for the first stroke avoids triggering it.
  • to evaluate [nNote] Recognition icons need explanation: the handwriting-"W" recognition has three icons - quite a few options, and it's hard to tell when to use which mode (you have to guess); a description is suggested.
  • to evaluate [nNote] Auto-enter edit after Insert: after handwriting-"W" Insert, it would be handier to auto-enter the text-edit state.
  • to evaluate [nNote] Multi-select notes → move to folder: HP wants multi-selected notes to move to a folder for easier organization.
  • to evaluate [nNote] Toolbar show / hide: after expanding, there is still writable space behind the toolbar, but switching to another tool gets blocked by the toolbar.
