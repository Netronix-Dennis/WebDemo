5. 跨平台同步討論摘要(與 Gourav) 討論摘要

近期與 Gourav 討論 HP Sync 整合的重點,已整理成獨立頁面。重點如下:

  • 格式差異:兩階段容器不同 - Demo 階段 FluxInk 輸出 .entinfo(容器);CES 階段 HP Note App(經 AIE SDK)輸出裸 .ent(單頁)。
  • 底層一致:兩者 ink 資料同為 HWPENKITDATA,差異僅在封裝層 - 匯入時以 magic byte 判斷分支即可互通。
  • AIE SDK 改名:FluxInk AIE SDK 產出副檔名由 .entinfo 改為 .inkF(格式內部仍為 ENT,僅名稱變更),Demo 工具不受影響。
  • Demo 合約已凍結:content(純文字)與 inkContent(FluxInk Base64)分離;size limit 由 8 MiB 提升至 32 MiB(下版生效)。

5. Cross-Platform Sync Discussion (with Gourav) discussion notes

Recent discussion with Gourav on HP Sync integration, written up as a standalone page. Key points:

  • Format difference: different containers per stage - Demo stage, FluxInk outputs .entinfo (container); CES stage, HP's Note App (via AIE SDK) outputs a bare .ent (single page).
  • Same underlying format: both carry the same HWPENKITDATA ink data; the difference is only in the packaging layer - interop just needs magic-byte branching on import.
  • AIE SDK rename: FluxInk's AIE SDK changed its output extension from .entinfo to .inkF (still ENT internally, name-only change); demo tools are unaffected.
  • Demo contract frozen: content (plain text) and inkContent (FluxInk Base64) are separated; size limit raised from 8 MiB to 32 MiB (effective next build).
