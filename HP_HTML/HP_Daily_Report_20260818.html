  • 文件存取:loadDocument / saveDocument。
  • 工具切換與生命週期:工具狀態保存、Activity 生命週期(onResume / onPause / onDestroy)。

2. NtxUtilSDK - Eink-Stroke Fast Handwriting SDK & Demo App SDK & Demo

The second part is NtxUtilSDK - an SDK for Eink-Stroke fast handwriting and related basic tools.
Planned delivery: the SDK and the Demo App source code.

APIs exposed by the SDK (overview)

  • Setup & init: add the AAR, add the handwriting View, create a HandwritingSession (attachSession / detachSession, setHandwritingEnabled, suspendHandWrite).
  • Pen selection (selectPen): Ballpoint, Fountain Pen, Brush.
  • Stroke attributes (StrokeAttributes): withTool / withColor / withThickness, setStrokeAttributes / getCurrentAttributes.
  • Color and thickness settings.
  • Eraser and clear (clear).
  • Undo / Redo (undo / redo).
  • Lasso selection.
  • Document I/O: loadDocument / saveDocument.
  • Tool switching & lifecycle: tool-state persistence, Activity lifecycle (onResume / onPause / onDestroy).

Demo App

The Demo App shows how to use the SDK APIs above; here we focus on the non-SDK feature demonstrations (items already in the SDK API are not re-listed). Non-SDK demos in this version:

  • Refresh-ghosting call demo.
Planned for a later version: e.g. OCR recognition, layers, etc.
