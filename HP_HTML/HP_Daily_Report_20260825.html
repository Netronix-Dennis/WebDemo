1. Release Info (FW v1.0.4 recap) released last week

FW v1.0.4 was released last week; this build's updates are recapped below (by module). The update / FW-install SOPs were shipped with the Release Note and are not repeated here.

UI features unlocked (previously hidden during POC)

  • Add page (ADD_PAGE).
  • Duplicate page (DUPLICATE_PAGE).
  • Multi-page management (MULTI_PAGE_MANAGEMENT).
  • Cover setting (COVER_SETTING).
  • Layer panel (LAYER_PANEL).
  • Table tool (TABLE_TOOL).
  • Vertical text box (TEXT_BOX_VERTICAL).
  • Cross-note hyperlink (CROSS_NOTE_HYPERLINK).
  • Partial eraser (PARTIAL_ERASER).

Pre-Install

  • Pre-install the 15 APKs provided by HP.
  • Per Gourav's requirement, pre-install the 15 APKs by default and replace nHome with the app designated by Gourav.

All Apps

  • Remove Dropbox & Evernote.
  • Remove sttDemo: this version is not yet complete and recognition speed still needs further tuning, so it is removed for now.

nOCR

  • Shape-recognition polish.
  • Add Japanese / Korean text-model options.
  • Introduce vertical Chinese writing recognition.

nNote

  • Active-pen side button back to default;
    and per requirement - if the previous tool no longer exists, switch to the eraser.
  • Introduce Pattern non-pure-color options.

Gallery

  • Remove the swipe page-turn animation.

nTools

  • Switch the app list to a tabbed view.

Settings

  • Remove the Feedback page.
  • Introduce Google Play.

Bug fixes (fixed in this build)

  • Gallery: fix "after capturing a new photo, returning to Gallery does not show the latest photo".

2.1 Provide a version usable by end users

  • This week we plan to provide a version usable by end users.
  • Revert the current Home app back to the original nHome (restore nHome as Home);
    the 15 HP APKs remain pre-installed.

2.2 NtxUtilSDK demo items (planned)

Outline the planned NtxUtilSDK demo items;
these are not part of the SDK itself - they demonstrate how to use it:

  • Multi-Layer feature demo.
  • nOCR - AIDL method integration (demonstrate how to integrate nOCR via AIDL).

2.3 Planned together for the next version next version

The following two features are planned to be provided together in the next version:

  • After a handwriting insertion, auto-focus the text box.
  • Stylus Calibration: raised priority, introduce calibration.

3. Known Issues / Follow-up Tracking tracking

nNote / aDraw

  • Render the current note screen directly, no longer showing the previous screen first;
    need to test whether MTK device speed is fast enough.
  • Loading Notes is slower, suspected to be related to pen-type rendering.
  • When recognizing mixed sizes, only large characters show; small ones are ignored.
  • When the toolbar expands, the canvas gets blocked; evaluate a better approach (UX, not changed for now).
  • Introduce Pencil / Highlighter and their related non-pure-color patterns.
  • Stroke drop-out on continuous writing + rendering slowdown (aDraw) - ongoing tracking.

BSP

  • Taps don't always respond.
  • Unplugging Type-C mid-charge garbles the screen.
  • PalmTouch: the first stroke flies off or is affected.
  • Active-pen battery-level retrieval & vibration integration.
  • aDraw region bug when rotating.

Settings

  • Stylus Battery: status bar, low-battery warning, fetch on Refresh.

nOCR

  • Shape recognition: FluxInk's recognition covers shapes / text / math formulas, which must be integrated together.
