1. 上週 Release 版本修正回顧(v1.0.3) 上週釋出

快速手寫層(aDraw)

  • 鋼筆演算法已接上:本版包含鋼筆的快速手寫層渲染。
  • 延續毛筆(粗細與純色設定);尚未支援的筆種與色項 UI 暫時隱藏。

Camera / Gallery / 媒體播放

  • Camera:拍攝並確認後直接進入 Gallery;移除 FPS 顯示與相關 Debug 設定。
  • Gallery:影片模式支援 DU、白底 UI。
  • nMediaPlayer:播放檔案名稱修正。
  • 架構調整:Gallery 自 Tools 移除;nImage / nMediaPlayer 新增搜尋 Camera 儲存路徑,仍能讀取相機拍攝媒體。

Bug 修正 已修

  • PD 充電(PD Driver):對齊 IBP、5V / 9V / 12V PD charging;9V 穩定度 finetune。
    DQA 測試,以 HP 筆電的 Adapter 充電已達 12V。

文字辨識(OCR)說明

  • Multi Language 改名 Latin Language:原僅含拉丁語系,辨識中文會不準,改名避免誤會。
  • 套索辨識準確度較整頁 OCR 低(待 HP 提供 .note 分析)。
  • 繁 / 簡:繁體語言包本含部分簡寫字,筆跡相近時會辨成該字。
  • 字母大小寫辨識(待 HP 提供操作與 .note)。
  • OCR 工具 icon:手寫辨識(插入 / 取代)、圖形混合辨識、數學公式辨識。

1. Last Week's Release Recap (v1.0.3) released last week

Fast handwriting layer (aDraw)

  • Fountain-pen algorithm is connected: this build includes fountain-pen fast-handwriting rendering.
  • Continues the brush pen (thickness & solid-color settings); UI for not-yet-supported pen types / colors is hidden.

Camera / Gallery / media playback

  • Camera: after capture & confirm, go directly to Gallery; remove FPS display and related debug settings.
  • Gallery: video mode supports DU and a white-background UI.
  • nMediaPlayer: fix the playback file name.
  • Architecture: remove Gallery from Tools; nImage / nMediaPlayer additionally search the Camera storage path, and can still read camera-captured media.

Bug fixes fixed

  • PD charging (PD Driver): align with IBP, 5V / 9V / 12V PD charging; finetune 9V stability.
    In DQA testing, charging with an HP laptop adapter reached 12V.

Text recognition (OCR) notes

  • Multi Language renamed to Latin Language: it only contained Latin-family types, so Chinese was inaccurate; renamed to avoid confusion.
  • Lasso recognition is less accurate than full-page OCR (pending HP's .note).
  • Traditional / Simplified: the Traditional pack contains some variant chars; similar strokes may resolve to those.
  • Upper / lower case recognition (pending HP's operation notes and .note).
  • OCR tool icons: handwriting recognition (insert / replace), hybrid shape recognition, math-formula recognition.
