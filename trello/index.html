Trello 應用程式隱私權政策

最後更新：2026 年 9 月 17 日  ·  Last updated: 17 September 2026

這是一個內部自用的整合工具，不是公開發行的 Power-Up。 本應用程式僅由作者本人以自己的 Trello 帳號授權使用，不對外提供安裝， 也不會出現在任何其他使用者的看板上。
This is a private, single-user integration for internal engineering use. It is not distributed publicly and is not installed on any third party's boards.

1. 這個應用程式是什麼

Netronix-Dennis 是振曜科技（Netronix Inc.）內部工程團隊使用的 Trello 整合工具。它透過 Trello 官方 REST API，把團隊既有的 Trello 看板 與內部的工程輔助系統串接起來，用途包含：查詢卡片與討論內容、彙整工作進度、 分析停滯項目，以及在授權範圍內建立與更新卡片。

Netronix-Dennis is an internal engineering integration used at Netronix Inc. It connects existing Trello boards to internal tooling via Trello's official REST API in order to read cards and discussions, summarise progress, analyse stalled work, and create or update cards within the granted scope.

2. 我們存取哪些資料

本應用程式使用「應用程式擁有者本人」的 Trello API token 運作， 因此只能存取該帳號原本就看得到的看板。 授權範圍為 read 與 write， 未要求 account 權限。

資料類型說明
看板 / 清單名稱、識別碼、排序、可見度設定
卡片標題、描述、到期日、標籤、所屬清單、最後異動時間
留言卡片上的討論內容與發言者顯示名稱
附件檔名與連結（不主動下載檔案內容）
檢查清單項目名稱與完成狀態
成員顯示名稱與使用者名稱，用於辨識卡片負責人
活動紀錄建卡、移卡、留言等操作軌跡

本應用程式不會存取使用者的密碼、付款資訊， 也不會讀取應用程式擁有者權限範圍以外的任何看板。

3. 我們如何使用這些資料

  • 顯示與查詢看板內容，供內部團隊參考
  • 彙整工作進度、產生內部報告與停滯分析
  • 在使用者明確指示下建立卡片、新增留言、移動卡片或更新欄位

資料僅用於上述內部營運目的。我們不會為了廣告、 剖析個人行為，或任何與振曜內部工程作業無關的目的使用這些資料。

4. 資料的儲存與保存

  • 資料以即時方式向 Trello API 取得，預設不建立長期資料庫。
  • 為了產生報告而匯出的檔案，僅保存在振曜內部受控的儲存位置。
  • API 金鑰（token）僅存放於伺服器本機設定檔，權限限制為擁有者可讀， 且已排除於版本控制之外。

5. 資料分享

我們不販售、不出租、不向任何第三方分享從 Trello 取得的資料。 資料不會離開振曜內部系統，除了 Trello 本身之外，不會傳送給其他外部服務。

We do not sell, rent, or share Trello data with any third party. Data does not leave Netronix's internal systems.

6. 刪除行為的限制

本應用程式在設計上完全不具備刪除功能。 可執行的最具破壞性的操作為「封存（archive）」，且封存後可隨時還原。 任何永久刪除都必須由使用者親自在 Trello 介面上操作。

By design, this application implements no delete operations. The most destructive action available is archiving, which is reversible.

7. 撤銷授權

應用程式擁有者可隨時於 Trello 帳號設定 → Security 撤銷本應用程式的 token。撤銷後，本應用程式將立即失去所有存取能力。

8. 安全措施

  • 所有與 Trello 之間的通訊皆使用 HTTPS 加密
  • token 不寫入程式碼、不進版本控制、不記錄於日誌
  • 內部 HTTP 介面需通過金鑰標頭驗證才能呼叫
  • 授權範圍最小化：僅申請 read 與 write

9. 政策變更

本政策如有修訂，將直接更新本頁面並同步調整頁首的「最後更新」日期。
